### 招投标信息自动化处理与渠道线索管理

Channel Lead Collector 从公开招投标公告中提取与中标相关的企业信息，识别潜在渠道合作伙伴，支持增量采集、结构化处理、Excel 导出及飞书多维表格同步。

**本仓库是面向招聘人员和面试官的项目文档展示，不是面向公众的生产服务，也不是可直接运行的软件发行包。** 文档介绍一套现有的本地 macOS 应用，不提供业务源码、真实运营数据、凭据或内部文档。技术内容的公开仍应遵守项目所有者适用的知识产权和保密要求。

## 项目概览

项目将实际业务流程与浏览器自动化、本地 Web 界面、结构化数据处理及外部协作平台连接起来。它的范围不止网页采集：使用者可以定义搜索条件、查看进度、保留项目历史、导出结果、预览同步计划，并明确确认是否写入外部系统。

我的主要职责是定义工作流、提出产品与安全要求、使用 Codex 推动迭代开发，以及审阅验收结果。AI 辅助了代码实现、测试和文档编写。具体职责与归属边界见[个人贡献说明（英文）](MY_CONTRIBUTIONS.md)。

## 业务问题

从招投标公告中寻找潜在合作伙伴，通常需要反复搜索、打开公告详情、区分供应商与采购单位、记录信息来源，并检查企业是否已收录。将结果整理到共享表格时，还可能产生重复记录或覆盖人工维护的信息。

工程目标是让这一流程可以重复执行、便于核查，同时保留使用者对登录和外部写入的控制。本项目没有声称经过量化验证的效率提升、营收或用户采用成果。

## 解决方案

使用者在本地 Web 界面输入关键词。Playwright 操作招投标平台中的搜索与详情页面，包括嵌入式 iframe。采集器跳过已处理的历史项目，按明确的字段优先级提取企业信息，并过滤重复结果。系统导出 Excel，再生成飞书多维表格同步计划，由使用者审阅后决定是否写入。

中标候选人可以作为潜在线索，**但不能据此认定已经最终中标或签约**。结果保留所选来源字段和公告链接，便于人工复核。

## 核心功能

以下能力已存在于底层实现中；各项验证程度在后文单独说明。

- 自定义关键词搜索、数量控制、自动翻页和进度展示。
- 通过持久化本地浏览器上下文，复用使用者人工完成的登录状态。
- 根据项目 ID、规范化 URL 及备用标识进行历史项目去重。
- 结构化解析公告，按优先级提取企业字段并保留信息来源。
- 基于已有结果进行增量采集，输出格式化 Excel。
- 企业去重与飞书同步：补充空字段，保留已有非空字段。
- 只读同步预览、源文件变更检查，以及独立的写入确认操作。
- 在本地网页配置飞书参数，并对 Secret 的保存与响应进行保护。
- 在 macOS 自动部署项目私有 Python、锁定依赖和 Chromium。
- 环境自检、Chromium 定向修复、重复安装检查，以及识别项目进程的安全启动与停止。

## 系统架构

```mermaid
flowchart LR
    A[使用者与本地 Web 界面] --> B[FastAPI 任务编排]
    B --> C[Playwright 采集器]
    C --> D[项目历史与结构化提取]
    D --> E[企业过滤与 Excel 输出]
    E --> F[飞书 dry-run 预览]
    F --> G{使用者确认}
    G -->|确认| H[写入飞书多维表格]
    G -->|暂缓| I[保留本地结果]
```

界面与 API 在本地运行，采集任务交由 Python 子进程执行，Web 服务展示状态和进度。环境管理是配套子系统，不是云服务。完整流程与技术分层见[架构说明（英文）](ARCHITECTURE.md)。

## 工程挑战

主要工程决策围绕可靠性和操作边界展开：在动态网页中找到正确的 frame、使用稳定的项目标识、保留企业信息来源、区分扫描数量与有效结果目标，以及要求外部写入前具有有效的同步预览。

部署还带来了另一项挑战：同事应能在没有预装 Python 开发工具链的 Mac 上开始使用。实现将解释器、依赖和浏览器放在项目目录中，并通过实际环境检查判断安装状态是否有效。

## 部署设计

底层 Mac 应用提供首次安装、启动和停止三个 command 入口。首次安装检测 macOS 与 CPU 架构，下载并校验私有 Python runtime，创建根目录虚拟环境，安装哈希锁定依赖，并准备项目私有 Chromium。后续执行检查并复用健康组件，必要时修复对应阶段。

在 Python 与依赖层健康时，Web 界面可以修复 Chromium。解释器、虚拟环境或依赖层损坏时，需要通过外部安装器恢复。环境就绪不等于已配置飞书，也不等于已经登录招投标平台。

声明的最低系统版本为 macOS 14。现有记录表明，Apple Silicon 已在一个较新 macOS 测试配置上通过 RC1 安装与环境验收。Intel 的 runtime 与依赖选择已准备，但仍待真机验证；不能据此认为所有支持范围内的系统版本和芯片代际都已测试。

## 安全与负责任的自动化

- 使用者须使用本人合法授权的剑鱼账号，并遵守适用的访问条件。登录、扫码与真人验证由人工完成，系统不提供绕过验证码或访问控制的功能。
- 底层 Web 服务监听本地回环地址，面向本机操作者使用，不是经过公网多用户安全加固的服务。
- 浏览器登录状态与飞书凭据属于本地运行材料，不包含在展示仓库中。
- 同步预览不写入飞书，但可能通过网络读取已有记录；写入是独立操作。
- 企业匹配采用确定性规则，不保证识别法律实体。对含义不明确的供应商名称和候选公告仍需人工复核。
- 技术描述的公开须符合所有者的披露权限；能够访问 Private 项目不代表有权公开其内容。
